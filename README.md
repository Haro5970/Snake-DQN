# Snake DQN

PyGame으로 만든 Snake 환경에서 강화학습 에이전트를 실험한 프로젝트입니다. 간단한 Q-Table 기반 접근에서 시작해, 게임판 상태를 신경망에 입력하는 DQN 방식으로 확장했습니다.

## 프로젝트 흐름

1. **Q-Table 실험** — 상태와 행동의 가치를 표로 관리하는 방식으로 Snake 게임의 행동 학습을 시도했습니다.
2. **DQN 적용** — 게임판을 격자 상태로 표현하고, Keras 신경망이 행동별 Q값을 추정하도록 구성했습니다. 에이전트는 직진·좌회전·우회전 중 하나를 선택합니다.
3. **시뮬레이션과 학습 분리** — PyGame 시뮬레이션과 DQN 학습기를 Flask API로 분리했습니다. API를 사용한 이유는 게임 시뮬레이션과 학습을 별도 프로세스로 실행해 각각 독립적으로 돌리고 조정해보려는 시도였습니다. 게임은 상태를 보내 행동을 받고, 다음 상태와 보상을 학습기에 전달합니다.

## 구성

- `test.py` — Snake 시뮬레이션, 상태 생성, 에피소드 실행 및 API 호출
- `main.py` — Flask 서버와 DQN 에이전트 API
- `DQN_class.py` — 신경망 구성, 행동 선택, 경험 저장, 학습 및 모델 저장
- `*_obj.json` — 일부 실험의 에피소드별 먹이 점수 기록
- `models/` — 실행 중 저장되는 모델 설정, 경험 메모리와 가중치

## 학습 흐름

각 에피소드에서 게임 상태를 만들고, 에이전트가 선택한 행동을 Snake 환경에 적용합니다. 먹이 획득, 충돌, 일반 이동에 서로 다른 보상을 주고, 상태·행동·보상·다음 상태를 메모리에 저장해 학습에 사용합니다. 실험 로그의 점수는 한 에피소드 동안 먹은 사과 수입니다.

## 실행

Python 환경에 필요한 패키지를 설치합니다.

```bash
pip install flask tensorflow pygame numpy requests matplotlib
```

Flask 학습 서버와 게임 시뮬레이션을 각각 별도 터미널에서 실행합니다.

```bash
# 터미널 1: DQN API 서버
python main.py

# 터미널 2: Snake 시뮬레이션
python test.py
```

서버는 기본적으로 `http://127.0.0.1:8000`에서 실행됩니다. 현재 클라이언트 코드도 같은 주소를 사용합니다.

## API

에이전트 이름을 경로에 넣어 호출합니다. 기본 실험 코드는 `DQ2` 에이전트를 사용합니다.

| 경로 | 메서드 | 기능 |
|---|---|---|
| `/<name>/init` | POST | 에이전트와 신경망 초기화 |
| `/<name>/act` | POST | 현재 상태에 대한 행동 선택 |
| `/<name>/memorize` | PUT | 경험 저장 |
| `/<name>/fit` | GET | 저장된 경험으로 학습 |
| `/<name>/save` | PUT | 설정, 경험 메모리와 가중치 저장 |
| `/<name>/epsilon` | GET | 현재 탐험 비율 확인 |

## 실험 기록

저장된 `*_obj.json` 파일에 에피소드별 점수가 기록되어 있습니다. 실험마다 설정과 실행 횟수가 달라, 이 기록은 동일 조건의 성능 비교보다는 학습 과정을 살펴보는 자료로 활용합니다.

> 학습용 프로토타입입니다. 재현 가능한 비교 실험이나 안정적인 학습 성능을 검증한 프로젝트는 아닙니다.
